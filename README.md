# Lee Kuan Yew RAG Chatbot

## Overview

This project is a Retrieval-Augmented Generation (RAG) chatbot built with Flowise.

It answers questions from the perspective of Lee Kuan Yew by retrieving relevant information from a knowledge base containing speeches, memoirs, interviews, and articles before generating a response.

## Features

- Flowise chatbot
- RAG architecture
- Document retrieval
- Gemini 3 Flash Preview
- Grounded responses
- Evaluation test cases

## Technical Architecture

User Question
        ↓
Retriever
        ↓
Knowledge Base
        ↓
Gemini 3 Flash Preview
        ↓
Response
